---

## ✨ Features

- 💻 **Mind-Blowing 3D Hero Workstation**: Floating cyber laptop with real-time dynamic code telemetry, glowing holographic neural brain mesh, and orbiting satellites.
- 🪐 **Interactive 3D Skills Constellation**: Concentric orbital universe of technologies, algorithms, AI architectures, and cloud platforms with real-time live telemetry HUD.
- 🏆 **3D Holographic Achievement Showcase**: Interactive 3D Trophy showcasing 65+ Google Skill Badges and 30+ Microsoft Learn Badges & Trophies.
- 🚀 **Featured Project Deep Dives**: 3D parallax cards for **Job Junction** and **AI Health Assistant** with architectural modal breakdown.
- ⚡ **Curated Live GitHub Stream**: Real-time public repositories dynamically loaded from `@rajsatyamraj03-collab`.
- 📄 **Interactive Resume & PDF Suite**: In-browser curriculum vitae viewer with one-click print and PDF generation.
- 🔊 **Synthesized Cyber Audio & Custom Glowing Cursor**: Lightweight Web Audio API sound FX (laser clicks, cyber hover, warp pulses) with instant mute toggle.
- ⌨️ **Command Palette**: `Cmd + K` / `Ctrl + K` quick navigation modal across all sections and resources.

---

## 🛠️ Tech Stack

- **Framework**: Next.js 14 (App Router)
- **Language**: TypeScript
- **3D Graphics**: Three.js, React Three Fiber (`@react-three/fiber`), Drei (`@react-three/drei`)
- **Styling**: Tailwind CSS & Glassmorphism
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Audio**: Web Audio API Synthesizer

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/rajsatyamraj03-collab/3D_Portfolio.git
cd 3D_Portfolio
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) to view the application.

### 4. Build for production
```bash
npm run build
npm run start
```
